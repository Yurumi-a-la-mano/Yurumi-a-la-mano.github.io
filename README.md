# Yurumí a la mano

Caja de herramientas de gestión ambiental de la Universidad El Bosque (Facultad de Ciencias y Museo de Ciencias), con los proyectos de campo realizados en la RNSC Yurumí (Puerto López, Meta).
Grupo de gestión ambiental, ecosistemas terrestres y biología tropical · 2026-2.

Sitio publicado: https://yurumi-a-la-mano.github.io

## Cómo está organizado

- `index.html`: el sitio completo. Es una sola página; cada vista (inicio, proyectos, fichas, notas, pósteres, acerca de) se arma con JavaScript a partir del bloque de datos `DATA` que está dentro del archivo.
- `img/`: logos, foto del grupo, fotos de las fichas (`fotos/`) y vistas previas de fichas, notas y pósteres (`fichas/`, `notas/`, `posters/`).
- `recursos/fichas/`, `recursos/notas/`, `recursos/posters/`: PDF originales. El sitio los enlaza por su nombre; no se deben borrar ni renombrar.
- `_borrador-v1/`: generador del primer borrador (versión anterior, ya no se usa). GitHub Pages no publica esta carpeta.

Respaldos: las ramas `respaldo-2026-10-19`, `respaldo-borrador-v1-2026-11-04` y `respaldo-artefacto-v5-2026-11-05` guardan las versiones anteriores del sitio (incluidas las fichas viejas).
