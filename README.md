# Yurumí a la mano

Caja de herramientas de gestión ambiental de la Universidad El Bosque (Facultad de Ciencias y Museo de Ciencias), con los proyectos de campo realizados en la RNSC Yurumí (Puerto López, Meta).
Grupo de gestión ambiental, ecosistemas terrestres y biología tropical · 2026-2.

Sitio publicado: https://yurumi-a-la-mano.github.io

## Cómo está organizado

- `index.html`: el sitio completo. Es una sola página; cada vista (inicio, proyectos, fichas, notas, acerca de) se arma con JavaScript a partir del bloque de datos `DATA` que está dentro del archivo.
- `img/`: logos, foto del grupo, fotos de proyectos y fichas, e imágenes de las fichas.
- `recursos/pdf/`: PDF originales de las fichas. El sitio los enlaza; no se deben borrar ni renombrar.
- `_borrador-v1/`: generador del primer borrador (versión anterior, ya no se usa). GitHub Pages no publica esta carpeta.

Respaldos: las ramas `respaldo-2026-10-19` y `respaldo-borrador-v1-2026-11-04` guardan las versiones anteriores del sitio.
